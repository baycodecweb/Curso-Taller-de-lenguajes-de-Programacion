I. Objetivo de la Guía

Construir la primera interfaz gráfica de usuario (GUI) en Java utilizando componentes básicos (JFrame, JLabel, JTextField, JButton) y programar la interactividad mediante la Programación Orientada a Eventos (POE) con Listeners.

III. Marco Teórico Breve

📦 1. ¿Qué es una librería (biblioteca) de código?

Antes de hablar de Swing, conviene entender qué es una librería (también llamada biblioteca) en programación: es un conjunto de clases y funciones que otras personas ya programaron, probaron y empaquetaron para que cualquier desarrollador las reutilice, en lugar de escribir todo desde cero.

Es como una caja de herramientas: si necesitas atornillar algo, no fabricas un destornillador nuevo, tomas el que ya existe en la caja y lo usas. En Java pasa lo mismo: cuando escribes import javax.swing.*;, le estás diciendo al programa "quiero usar las herramientas (clases) que trae el paquete javax.swing". Gracias a eso, no necesitas programar tú mismo cómo se dibuja un botón en pantalla: simplemente usas la clase JButton que la librería ya te ofrece, lista para usar.

🪟 2. ¿Qué es Java Swing y los Componentes Básicos?

Java Swing es, precisamente, un ejemplo concreto de librería: es la biblioteca gráfica de Java que permite crear aplicaciones de escritorio sin programar el dibujo de cada botón o ventana a bajo nivel. Los elementos principales son:

  • JFrame: La ventana principal de la aplicación.
  • JLabel: Etiquetas para mostrar texto o imágenes estáticas.
  • JTextField: Cajas de texto donde el usuario puede escribir información (ej. su nombre de usuario).
  • JButton: Botones interactivos que ejecutan acciones al ser presionados.

🖱️ 3. Programación Orientada a Eventos (POE)

A diferencia de los programas secuenciales tradicionales, en una interfaz gráfica el flujo del programa depende de las acciones del usuario (eventos como hacer clic en un botón, mover el mouse, etc.). Se utiliza la interfaz ActionListener para "escuchar" cuándo ocurre un clic y reaccionar ante él.

⚠️ Errores Comunes al Empezar

❌ Error típico: Crear un componente con new JButton(...) pero olvidar agregarlo con add(...). El programa compila sin problema, pero el botón nunca aparece en pantalla.

✅ Cómo evitarlo: Todo componente que crees debe agregarse a la ventana (o a un panel) con add(); si no lo haces, Java simplemente lo "olvida".

❌ Error típico: Usar setLayout(null) pero olvidar el setBounds(...) en algún componente.

✅ Cómo evitarlo: Con layout null, CADA componente necesita su propio setBounds(x, y, ancho, alto); si falta, aparece en la esquina (0,0) o no se ve.

❌ Error típico: Escribir la lógica del clic pero olvidar boton.addActionListener(...), o no implementar ActionListener en la clase.

✅ Cómo evitarlo: El botón necesita "saber" quién lo escucha: revisa que la clase implemente ActionListener y que hayas registrado el listener con addActionListener().

IV. Actividades Prácticas Paso a Paso

PASO 1

Desarrollo del Trabajo 1 (Diseño de la Interfaz Visual)

Crea una clase en Java llamada GameStoreLogin.java dentro de tu entorno de desarrollo (NetBeans, Eclipse o IntelliJ). Esta clase debe heredar de JFrame para construir la ventana de acceso con los componentes básicos pedidos en el sílabo.

JAVA 
import javax.swing.*;
import java.awt.*;

public class GameStoreLogin extends JFrame {
    // Declaración de componentes básicos
    private JLabel lblTitulo, lblUsuario;
    private JTextField txtUsuario;
    private JButton btnIngresar;

    public GameStoreLogin() {
        // Configuración de la Ventana Principal (JFrame)
        setTitle("GameStore Escolar - Acceso");
        setSize(350, 200);
        setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        setLocationRelativeTo(null); // Centrar ventana
        setLayout(null); // Diseño libre para ubicar componentes por coordenadas

        // Inicialización y posicionamiento de componentes (JLabel, JTextField, JButton)
        lblTitulo = new JLabel("BIENVENIDO A GAMESTORE");
        lblTitulo.setBounds(70, 20, 200, 25);
        lblTitulo.setFont(new Font("Arial", Font.BOLD, 12));
        add(lblTitulo);

        lblUsuario = new JLabel("Usuario:");
        lblUsuario.setBounds(40, 70, 80, 25);
        add(lblUsuario);

        txtUsuario = new JTextField();
        txtUsuario.setBounds(110, 70, 180, 25);
        add(txtUsuario);

        btnIngresar = new JButton("Ingresar");
        btnIngresar.setBounds(110, 110, 100, 30);
        add(btnIngresar);
    }

    public static void main(String[] args) {
        // Ejecutar la interfaz
        new GameStoreLogin().setVisible(true);
    }
}

PASO 2

Desarrollo del Trabajo 2 (Programación de Eventos de Clic)

Ahora, añade la lógica de eventos utilizando un ActionListener al botón btnIngresar. Esto permitirá que al hacer clic se capture el texto digitado y se muestre un mensaje emergente de bienvenida.

Modifica el constructor o añade la siguiente estructura dentro de tu código:

JAVA 
import javax.swing.*;
import java.awt.*;
import java.awt.event.ActionEvent;
import java.awt.event.ActionListener; // Importar para los eventos

public class GameStoreLogin extends JFrame {
    private JLabel lblTitulo, lblUsuario;
    private JTextField txtUsuario;
    private JButton btnIngresar;

    public GameStoreLogin() {
        setTitle("GameStore Escolar - Acceso");
        setSize(350, 200);
        setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        setLocationRelativeTo(null);
        setLayout(null);

        lblTitulo = new JLabel("BIENVENIDO A GAMESTORE");
        lblTitulo.setBounds(70, 20, 200, 25);
        add(lblTitulo);

        lblUsuario = new JLabel("Usuario:");
        lblUsuario.setBounds(40, 70, 80, 25);
        add(lblUsuario);

        txtUsuario = new JTextField();
        txtUsuario.setBounds(110, 70, 180, 25);
        add(txtUsuario);

        btnIngresar = new JButton("Ingresar");
        btnIngresar.setBounds(110, 110, 100, 30);
        add(btnIngresar);

        // --- PROGRAMACIÓN DEL EVENTO DE CLIC (TRABAJO 2) ---
        btnIngresar.addActionListener(new ActionListener() {
            @Override
            public void actionPerformed(ActionEvent e) {
                // Capturar el texto ingresado en el JTextField
                String usuarioIngresado = txtUsuario.getText();

                // Validar si el campo no está vacío
                if (!usuarioIngresado.isEmpty()) {
                    JOptionPane.showMessageDialog(null,
                        "¡Acceso concedido! Bienvenido, " + usuarioIngresado + ".",
                        "GameStore", JOptionPane.INFORMATION_MESSAGE);
                } else {
                    JOptionPane.showMessageDialog(null,
                        "Por favor, ingrese un nombre de usuario.",
                        "Advertencia", JOptionPane.WARNING_MESSAGE);
                }
            }
        });
    }

    public static void main(String[] args) {
        new GameStoreLogin().setVisible(true);
    }
}

🤔 Antes de seguir: ¿qué crees que pasaba si hacías clic en "Ingresar" ANTES de agregar este código del Paso 2 (el ActionListener)?

Nada — la ventana se veía exactamente igual, el botón se hundía visualmente al presionarlo, pero no ocurría ninguna acción, porque todavía no le habías dicho a Java QUÉ hacer cuando eso pasara. Eso es justo lo que agrega el ActionListener de este Paso 2.
