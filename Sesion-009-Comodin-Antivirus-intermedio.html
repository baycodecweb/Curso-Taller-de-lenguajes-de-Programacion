🚀 Cómo ejecutar este proyecto

Necesitás el JDK 17 o superior. Igual que el nivel básico: compilar primero, ejecutar después. Al arrancar, se abren a la vez la ventana y el servicio de fondo (monitor de carpeta + socket IPC), en la misma aplicación.

🐧 Linux / macOS

  1. Abrí una terminal dentro de la carpeta Antivirus-baycodec-nivel-intermedio/.
  2. Compilá (primera vez, o tras cambiar un .java):./compile.sh
  3. Ejecutá:./run.sh

🪟 Windows

  1. Entrá a la carpeta windows\.
  2. Compilá con doble clic en compile.bat, o desde cmd:windows\compile.bat
  3. Ejecutá con doble clic en run.bat, o desde cmd:windows\run.bat

Si ./compile.sh o ./run.sh dan "Permission denied", corré chmod +x compile.sh run.sh una sola vez. La primera vez que se ejecuta se crean solos config.properties, carpeta-vigilada/ y cuarentena/. El puerto 4859 (configurable en config.properties) es el socket IPC real entre la ventana y el servicio de fondo.

📖 Glosario para quien nunca programóTérminos nuevos de este nivel, además de los del nivel básico.
Hilo (Thread)
Una "línea de ejecución" independiente dentro del mismo programa. Este proyecto corre varios a la vez: uno dibuja la ventana, otro vigila la carpeta, otro escucha el socket — todos en el mismo proceso, sin bloquearse entre sí.
Socket
Un "enchufe" de red que permite que dos programas (o dos partes del mismo programa) se manden mensajes de texto o bytes, aunque estén en procesos separados. Acá se usa en 127.0.0.1 (la propia máquina) para la comunicación interna.
Enum
Un tipo de dato que solo puede valer una de un puñado de opciones fijas, escritas de antemano. Ej: TipoVirus solo puede ser TROYANO, GUSANO, RANSOMWARE, etc. — nunca cualquier otro texto.
Interfaz funcional / lambda
Un tipo como Consumer<String> o Runnable representa "una acción que se puede pasar como si fuera un dato" y ejecutar después. La sintaxis x -> hacer_algo(x) es una forma corta de escribirla.
WatchService
Una herramienta de Java que le pide al sistema operativo "avisame cuando algo cambie en esta carpeta", en vez de tener que estar revisando todo el tiempo a mano (polling).
ProcessHandle
La forma moderna que tiene Java de preguntarle al sistema operativo qué procesos están corriendo en la computadora (sin depender de comandos externos para listarlos).
Entropía (de un archivo)
Una medida de "qué tan aleatorio" se ve el contenido de un archivo. Texto normal tiene entropía baja/media; un archivo comprimido o cifrado tiene entropía muy alta — por eso sirve como pista heurística.
Heurística
Detectar algo "por señales sospechosas" en vez de por una firma exacta conocida. Es más flexible que el hash-matching, pero también puede equivocarse (falsos positivos) — por eso los antivirus reales combinan ambas técnicas.
Shutdown hook
Un pedazo de código que Java promete ejecutar automáticamente cuando el programa se está por cerrar (de forma normal o por una señal como Ctrl+C) — útil para dejar todo ordenado, aunque no protege contra un cierre forzado (kill -9).
ScheduledExecutorService
Una herramienta de Java para decir "ejecutá esta tarea cada N minutos, sola, en segundo plano" — sin tener que programar manualmente temporizadores.
ProcessBuilder
La forma en que un programa Java le pide al sistema operativo que ejecute OTRO programa (por ejemplo, un comando de terminal como id -u o systemctl) y lea su resultado.
Servicio del sistema (systemd/Windows Service)
Un programa registrado para que el propio sistema operativo lo arranque, vigile y reinicie solo — sin depender de que un usuario lo abra a mano. En Linux se maneja con systemd.
