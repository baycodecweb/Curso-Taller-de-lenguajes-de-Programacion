🚀 Cómo ejecutar este proyecto

Necesitás el JDK (Java Development Kit) 17 o superior instalado. Son dos pasos siempre: compilar (traducir el código Java a algo que la computadora entiende) y ejecutar (abrir la ventana del antivirus).

🐧 Linux / macOS

  1. Abrí una terminal dentro de la carpeta Proyecto-Antivirus/.
  2. Compilá (solo hace falta la primera vez, o después de cambiar un archivo .java):./compile.sh
  3. Ejecutá:./run.sh

🪟 Windows

  1. Entrá a la carpeta Proyecto-Antivirus\windows\.
  2. Compilá con doble clic en compile.bat, o desde cmd:windows\compile.bat
  3. Ejecutá con doble clic en run.bat, o desde cmd:windows\run.bat

Si ./compile.sh o ./run.sh dan "Permission denied", corré una sola vez chmod +x compile.sh run.sh para darles permiso de ejecución. No hace falta recompilar cada vez: solo cuando cambiás código Java. Al abrir la ventana, el botón "Seleccionar y escanear..." deja elegir un archivo o carpeta para analizar.

📖 Glosario para quien nunca programóTérminos que vas a ver una y otra vez en el código, explicados en español simple.
Clase (class)
Un molde que describe cómo es y qué sabe hacer un tipo de "cosa" en el programa. Ej: la clase Escaneador describe todo lo que un escáner sabe hacer.
Objeto
Una "cosa" concreta creada a partir de un molde (clase), usando la palabra new. Ej: new Escaneador(...) crea un objeto escáner real y usable.
Método (o función)
Un bloque de código con nombre que hace una tarea específica y se puede "llamar" (ejecutar) desde otras partes del programa cuando se necesita.
Variable
Un espacio con nombre donde se guarda un valor (un número, un texto, un archivo, etc.) para poder usarlo más adelante en el código.
Parámetro / argumento
Un valor que se le entrega a un método para que trabaje con él. Ej: en main(String[] args), args es un parámetro.
Atributo o campo (field)
Una variable que pertenece a una clase (o a un objeto) y guarda su información. Ej: escaneador es un atributo de VentanaPrincipal.
Constructor
Un método especial, con el mismo nombre que la clase, que se ejecuta automáticamente cada vez que se crea un objeto nuevo con new.
Paquete (package)
Un grupo de clases relacionadas. La línea package core; arriba de un archivo no "llama" a ninguna carpeta: es una declaración, como escribir tu apellido — le dice al compilador a qué grupo pertenece esa clase. La carpeta (src/core/) coincide con ese nombre solo por convención: es tan fuerte que casi todos la siguen, pero lo que realmente define el paquete es el package del archivo, no el nombre de la carpeta. Al compilar, javac lee esa línea y decide ahí adentro de qué carpeta poner el .class resultante.
import
Le avisa a Java "voy a usar esta clase que vive en otro paquete", para no tener que escribir su nombre completo (con paquete y todo) cada vez que se la nombra.
public
El nivel de acceso más abierto: cualquier otra clase, de cualquier paquete, puede ver y usar esto.
private
Lo opuesto a public: solo la propia clase puede usarlo, nadie de afuera tiene acceso directo.
static
Significa que algo pertenece a la clase en sí misma, no a un objeto en particular, y por eso se puede usar sin crear (new) nada primero.
final
"Esto no se puede volver a cambiar una vez definido." Una variable final se asigna una sola vez.
void
Significa que un método no devuelve ningún valor: solo realiza una acción y termina.
Tipo de dato
La clase de valor que puede guardar una variable. Ej: int (números enteros), boolean (verdadero/falso), String (texto).
this
Dentro de una clase, la palabra this se refiere "a mí mismo": al objeto actual que está ejecutando el código.
return
La palabra que hace que un método entregue un resultado hacia quien lo llamó, y termina su ejecución justo ahí.
if / else (condicional)
Permite que el programa tome un camino u otro según si algo es verdadero o falso. "Si pasa esto, hacé A; si no, hacé B."
for / while (bucle)
Repite un bloque de código varias veces. Ej: una vez por cada archivo dentro de una carpeta.
try / catch
"Intentá hacer esto; si algo sale mal, atrapá el error acá y decidí qué hacer", en vez de que el programa se rompa de golpe.
extends (herencia)
Dice que una clase "hereda" de otra: nace ya sabiendo hacer todo lo que sabe la clase de la que hereda. Ej: VentanaPrincipal extends JFrame ya es una ventana.
Interfaz (List, Set)
Un contrato que dice "cualquier cosa que cumpla esto debe saber hacer tal cosa", sin importar cómo lo resuelva por dentro.
