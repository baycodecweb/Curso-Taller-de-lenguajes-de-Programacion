III. Marco Teórico Breve

🧩 1. Administradores de Diseño (Layout Managers)

En la Guía N° 1 usaste setLayout(null) y coordenadas fijas (setBounds) para ubicar cada componente a mano — algo parecido a pegar los muebles al piso con cinta métrica: si el "cuarto" (la ventana) cambia de tamaño, los muebles no se mueven solos y todo se desordena.

Un administrador de diseño (Layout Manager) resuelve esto: en vez de darle a Java coordenadas exactas, le das reglas de organización (por ejemplo, "divide la ventana en 5 zonas" o "acomoda todo en una cuadrícula de 3×2"), y es la propia librería Swing la que calcula automáticamente la posición y el tamaño de cada componente, incluso si el usuario redimensiona la ventana.

Los dos que usarás en esta guía:

  • BorderLayout: Divide el contenedor en cinco regiones (BorderLayout.NORTH, SOUTH, EAST, WEST, CENTER).
  • GridLayout: Organiza los componentes en una cuadrícula de filas y columnas con celdas de igual tamaño.

🎛️ 2. Contenedores Avanzados y Componentes de Selección

  • JPanel: Un subcontenedor que permite agrupar varios componentes para organizarlos mejor dentro de un JFrame.
  • JScrollPane: Añade barras de desplazamiento automáticas a un panel cuando el contenido sobrepasa el tamaño visible.
  • JComboBox, JCheckBox, JRadioButton: Componentes que permiten al usuario elegir opciones mediante listas desplegables, casillas de verificación o botones de opción única.

⚠️ Errores Comunes al Empezar

❌ Error típico: Mezclar setLayout(null) con setBounds() y BorderLayout al mismo tiempo en el mismo contenedor.

✅ Cómo evitarlo: Cada contenedor (JFrame o JPanel) usa UN solo layout a la vez. Si usas BorderLayout, no llames a setBounds().

❌ Error típico: Escribir add(boton) en vez de add(boton, BorderLayout.SOUTH) al trabajar con BorderLayout.

✅ Cómo evitarlo: Siempre indica la zona explícita (NORTH, SOUTH, EAST, WEST o CENTER); si no, el componente reemplaza silenciosamente lo que había en CENTER.

❌ Error típico: Agregar muchos componentes con FlowLayout y sorprenderse de que "desaparecen" al achicar la ventana.

✅ Cómo evitarlo: Es el comportamiento normal de FlowLayout: pasa a la siguiente línea o se recorta según el espacio disponible; usa JScrollPane si necesitas garantizar que todo se vea.

IV. Actividades Prácticas Paso a Paso

PASO 1

Desarrollo del Trabajo 1 (Estructuración de Paneles y Layouts)

Crea una clase llamada CatalogoTienda.java que herede de JFrame. Vamos a estructurar la ventana utilizando BorderLayout en el fondo y un JPanel con GridLayout para mostrar las recompensas de forma ordenada, añadiendo además un JScrollPane.

JAVA 
import javax.swing.*;
import java.awt.*;

public class CatalogoTienda extends JFrame {
    private JPanel panelNorte, panelCentro, panelSur;
    private JLabel lblTituloCatalogo;
    private JButton btnCanjear, btnCerrar;
    private JScrollPane scrollPane;

    public CatalogoTienda() {
        setTitle("GameStore Escolar - Catálogo de Recompensas");
        setSize(500, 400);
        setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        setLocationRelativeTo(null);

        // Uso de BorderLayout para la ventana principal (Trabajo 1)
        setLayout(new BorderLayout());

        // Panel Superior (Norte)
        panelNorte = new JPanel();
        lblTituloCatalogo = new JLabel("TIENDA VIRTUAL - CANJE DE PUNTOS");
        lblTituloCatalogo.setFont(new Font("Arial", Font.BOLD, 14));
        panelNorte.add(lblTituloCatalogo);
        add(panelNorte, BorderLayout.NORTH);

        // Panel Central con GridLayout para los productos (Trabajo 1)
        panelCentro = new JPanel(new GridLayout(3, 2, 10, 10));
        panelCentro.setBorder(BorderFactory.createEmptyBorder(10, 10, 10, 10));

        // Simulando elementos del catálogo
        panelCentro.add(new JButton("Skin de Avatar (100 pts)"));
        panelCentro.add(new JButton("Pase de Tarea (200 pts)"));
        panelCentro.add(new JButton("Cursor Personalizado (50 pts)"));
        panelCentro.add(new JButton("Insignia Dorada (150 pts)"));
        panelCentro.add(new JButton("Fondo Exclusivo (80 pts)"));
        panelCentro.add(new JButton("Bonus Sorpresa (300 pts)"));

        // Envolver el panel central en un JScrollPane (Trabajo 1)
        scrollPane = new JScrollPane(panelCentro);
        add(scrollPane, BorderLayout.CENTER);

        // Panel Inferior (Sur)
        panelSur = new JPanel();
        btnCanjear = new JButton("Canjear Seleccionado");
        btnCerrar = new JButton("Salir");
        panelSur.add(btnCanjear);
        panelSur.add(btnCerrar);
        add(panelSur, BorderLayout.SOUTH);
    }

    public static void main(String[] args) {
        new CatalogoTienda().setVisible(true);
    }
}

🤔 Antes de seguir: si agregaras 6 botones con FlowLayout a una ventana angosta, ¿qué crees que pasaría?

No caben todos en una sola fila: FlowLayout los va acomodando uno al lado del otro, y en cuanto no queda espacio horizontal, empieza automáticamente una nueva fila — como el texto de un párrafo que salta de línea cuando ya no cabe una palabra más.

PASO 2

Desarrollo del Trabajo 2 (Integración de Componentes de Selección)

Modificaremos la parte superior de nuestro catálogo para incorporar un filtro por categorías usando un JComboBox, opciones adicionales con JCheckBox y tipos de envío o entrega mediante JRadioButton.

Añade y actualiza los componentes de selección en la clase:

JAVA 
import javax.swing.*;
import java.awt.*;

public class CatalogoTiendaAvanzado extends JFrame {
    private JComboBox<String> cmbCategorias;
    private JCheckBox chkNotificaciones;
    private JRadioButton rbtDigital, rbtFisico;
    private ButtonGroup grupoEnvio;
    private JPanel panelFiltros, panelCentro, panelSur;

    public CatalogoTiendaAvanzado() {
        setTitle("GameStore Escolar - Catálogo Avanzado");
        setSize(550, 450);
        setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        setLocationRelativeTo(null);
        setLayout(new BorderLayout());

        // --- PANEL DE FILTROS Y SELECCIÓN (TRABAJO 2) ---
        panelFiltros = new JPanel(new FlowLayout());

        // JComboBox para filtrar categorías
        cmbCategorias = new JComboBox<>(new String[]{"Todas las categorías", "Avatars", "Pases", "Accesorios"});
        panelFiltros.add(new JLabel("Filtrar:"));
        panelFiltros.add(cmbCategorias);

        // JCheckBox para opciones extra
        chkNotificaciones = new JCheckBox("Recibir alerta por correo");
        panelFiltros.add(chkNotificaciones);

        // JRadioButton y ButtonGroup para tipo de entrega
        rbtDigital = new JRadioButton("Digital", true);
        rbtFisico = new JRadioButton("Físico");
        grupoEnvio = new ButtonGroup();
        grupoEnvio.add(rbtDigital);
        grupoEnvio.add(rbtFisico);

        panelFiltros.add(rbtDigital);
        panelFiltros.add(rbtFisico);

        add(panelFiltros, BorderLayout.NORTH);

        // --- PANEL CENTRAL CON GRILLA (TRABAJO 1) ---
        panelCentro = new JPanel(new GridLayout(3, 2, 10, 10));
        panelCentro.add(new JButton("Skin de Avatar (100 pts)"));
        panelCentro.add(new JButton("Pase de Tarea (200 pts)"));
        panelCentro.add(new JButton("Cursor Personalizado (50 pts)"));
        panelCentro.add(new JButton("Insignia Dorada (150 pts)"));

        JScrollPane scrollPane = new JScrollPane(panelCentro);
        add(scrollPane, BorderLayout.CENTER);

        // Panel Sur
        panelSur = new JPanel();
        panelSur.add(new JButton("Canjear Ítem"));
        add(panelSur, BorderLayout.SOUTH);
    }

    public static void main(String[] args) {
        new CatalogoTiendaAvanzado().setVisible(true);
    }
}
