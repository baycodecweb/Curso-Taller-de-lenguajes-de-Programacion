I. Objetivo de la Guía

Implementar algoritmos que utilicen almacenamiento permanente mediante flujos de entrada y salida en archivos de texto plano y archivos binarios, controlando adecuadamente las excepciones de lectura y escritura (IOException).

III. Marco Teórico Breve

📁 1. Archivos de Texto (Text-File) vs. Archivos Binarios

  • Archivos de Texto: Almacenan información en caracteres legibles por humanos (como .txt). Se utiliza FileWriter, PrintWriter o BufferedReader.
  • Archivos Binarios: Almacenan los datos directamente en formato de bytes (como objetos serializados). Son más eficientes para respaldos o estructuras complejas y se utiliza FileOutputStream, ObjectOutputStream, etc.

🧯 2. Manejo de Excepciones (try-catch)

Las operaciones con archivos son propensas a errores externos (disco lleno, archivo inexistente, permisos denegados). Por ello, es obligatorio envolver el código en bloques try-catch para capturar excepciones como IOException.

Piensa en los flujos (streams) como tubos de agua encadenados: FileWriter es el tubo que llega directo al archivo, y PrintWriter es un embudo con forma más cómoda que conectas ENCIMA de ese tubo para verter el texto más fácilmente. Si el tubo se rompe a mitad de camino (el disco se llena, no hay permisos...), Java lanza una IOException, y el bloque catch es la bandeja que atrapa el derrame para que tu programa no se caiga por completo.

⚠️ Errores Comunes al Empezar

❌ Error típico: Usar código que puede lanzar IOException sin un try-catch ni un throws en la firma del método.

✅ Cómo evitarlo: Todo código de archivos es "riesgoso" para Java; siempre debe ir dentro de un try-catch, o el método debe declarar throws IOException.

❌ Error típico: Abrir un archivo para escribir sin cerrarlo (fuera de un try-with-resources).

✅ Cómo evitarlo: Usa siempre try-with-resources (try (FileWriter fw = ...)); Java cierra el archivo automáticamente al terminar, incluso si algo falla.

❌ Error típico: Intentar leer un archivo que todavía no existe, porque nunca se ejecutó el código que lo crea.

✅ Cómo evitarlo: Ejecuta primero el Paso que escribe/crea el archivo, antes de ejecutar el que lo lee.

IV. Actividades Prácticas Paso a Paso

PASO 1

Desarrollo del Trabajo 1 (Módulo de Registro en Texto Plano)

Crea una clase llamada HistorialLog.java que permita registrar en un archivo de texto cada vez que un estudiante realice un canje en la tienda del proyecto.

JAVA 
import java.io.FileWriter;
import java.io.PrintWriter;
import java.io.BufferedReader;
import java.io.FileReader;
import java.io.IOException;

public class HistorialLog {

    // Método para guardar un registro en archivo de texto (Trabajo 1)
    public static void registrarCanje(String estudiante, String itemCanjeado) {
        // Uso de FileWriter en modo append (true) para no sobrescribir el archivo
        try (PrintWriter pw = new PrintWriter(new FileWriter("historial_canjes.txt", true))) {
            pw.println("Estudiante: " + estudiante + " | Ítem: " + itemCanjeado);
            System.out.println("Registro de canje guardado exitosamente en el archivo de texto.");
        } catch (IOException e) {
            System.out.println("Error de E/S al escribir en el archivo de texto: " + e.getMessage());
        }
    }

    // Método para leer el historial de texto
    public static void leerHistorial() {
        try (BufferedReader br = new BufferedReader(new FileReader("historial_canjes.txt"))) {
            String linea;
            System.out.println("--- HISTORIAL DE CANJES (TEXT-FILE) ---");
            while ((linea = br.readLine()) != null) {
                System.out.println(linea);
            }
        } catch (IOException e) {
            System.out.println("No se encontró el archivo o hubo un error al leerlo: " + e.getMessage());
        }
    }
}

🤔 Antes de seguir: si ejecutas dos veces seguidas este programa (sin cambiar nada), ¿qué crees que pasará con el contenido del archivo en la segunda ejecución?

Se borra lo anterior — por defecto FileWriter sobrescribe el archivo desde cero cada vez que se abre. Para agregar líneas nuevas sin borrar las anteriores hay que abrirlo en modo "append" (un segundo parámetro true en el constructor de FileWriter).

PASO 2

Desarrollo del Trabajo 2 (Módulo de Respaldos Binarios)

Crea una clase llamada RespaldoBinario.java que permita guardar un respaldo cifrado o serializado de la configuración del sistema usando flujos binarios.

JAVA 
import java.io.FileOutputStream;
import java.io.ObjectOutputStream;
import java.io.FileInputStream;
import java.io.ObjectInputStream;
import java.io.IOException;

public class RespaldoBinario {

    // Método para guardar un objeto de configuración en archivo binario (Trabajo 2)
    public static void guardarRespaldoConfig(String configuracion) {
        try (ObjectOutputStream oos = new ObjectOutputStream(new FileOutputStream("config_respaldo.dat"))) {
            oos.writeObject(configuracion);
            System.out.println("Respaldo binario generado correctamente.");
        } catch (IOException e) {
            System.out.println("Error al escribir el archivo binario: " + e.getMessage());
        }
    }

    // Método para leer el respaldo binario
    public static void leerRespaldoConfig() {
        try (ObjectInputStream ois = new ObjectInputStream(new FileInputStream("config_respaldo.dat"))) {
            String configLeida = (String) ois.readObject();
            System.out.println("Configuración recuperada desde el binario: " + configLeida);
        } catch (IOException | ClassNotFoundException e) {
            System.out.println("Error al leer el archivo binario: " + e.getMessage());
        }
    }
}

Clase de ejecución

Puedes crear una clase PrincipalArchivos.java para ejecutar y probar ambos módulos:

JAVA 
public class PrincipalArchivos {
    public static void main(String[] args) {
        // Probando Text-File (Trabajo 1)
        HistorialLog.registrarCanje("Ana Torres", "Skin Legendario");
        HistorialLog.leerHistorial();

        // Probando Archivo Binario (Trabajo 2)
        RespaldoBinario.guardarRespaldoConfig("ModoMantto=false;Servidor=Activo");
        RespaldoBinario.leerRespaldoConfig();
    }
}
