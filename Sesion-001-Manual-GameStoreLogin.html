1. ¿Qué es este programa?

GameStoreLogin.java es la pantalla de acceso ("login") de la app GameStore Escolar, desarrollada como entregable de los dos trabajos de la Sesión 1:

  • Trabajo 1: interfaz visual con JFrame, JLabel, JTextField y JButton.
  • Trabajo 2: lógica de eventos con ActionListener — al pulsar "Ingresar" valida el campo de usuario y muestra un mensaje emergente.

2. Requisitos

Solo necesitas el JDK instalado (versión 17 o superior). Es gratuito y de código abierto — puedes descargarlo de adoptium.net (distribución Eclipse Temurin).

✅ Verificar instalación

Abre una terminal y escribe javac -version. Si responde con un número de versión, el JDK está listo.

3. Ejecutarlo por terminal (rápido)

PASO 1

Ubícate en la carpeta donde está el archivo:

$ cd Sesion-01/codigo
PASO 2

Compila el código fuente (genera los archivos .class):

$ javac GameStoreLogin.java
PASO 3

Ejecuta el programa:

$ java GameStoreLogin
→ Se abre la ventana "GameStore Escolar - Acceso"

4. Ejecutarlo con un IDE (recomendado para editar)

Si prefieres ver y modificar el código con resaltado de sintaxis, autocompletado y depurador, abre la carpeta Sesion-01/codigo con cualquiera de estos IDEs (todos gratuitos):

Apache NetBeans

Abre el archivo, clic derecho → Run File (o el botón ▶ verde).

IntelliJ IDEA Community

Abre la carpeta como proyecto, clic derecho sobre main → Run.

Eclipse IDE

Importa el archivo, luego Run As → Java Application.

VS Code

Instala la extensión Extension Pack for Java, abre el archivo y pulsa Run sobre el método main.

5. Cómo usarlo (guía de prueba)

Cuando aparezca la ventana, sigue este checklist para verificar que todo funciona:

  • Se abre la ventana con el título "GameStore Escolar - Acceso" y el texto "BIENVENIDO A GAMESTORE".
  • Escribe un nombre en el campo "Usuario" y pulsa Ingresar → debe aparecer el mensaje "¡Acceso concedido! Bienvenido, [nombre]."
  • Deja el campo vacío y pulsa Ingresar → debe aparecer la advertencia "Por favor, ingrese un nombre de usuario."
  • Cierra la ventana con la ✕ → el programa termina (por EXIT_ON_CLOSE).

6. Problemas comunes

⚠️ Solución a errores frecuentes

❌ javac: command not found

✅ El JDK no está instalado o no está en el PATH. Instálalo desde adoptium.net y reinicia la terminal.

❌ No se ve ninguna ventana al ejecutar java GameStoreLogin

✅ Estás en un entorno sin interfaz gráfica (por ejemplo, una conexión SSH sin X11). Ejecuta el programa en tu escritorio local, no en un servidor remoto sin pantalla.

❌ Error: Could not find or load main class GameStoreLogin

✅ No compilaste antes de ejecutar, o estás en otra carpeta. Ejecuta primero javac GameStoreLogin.java y confirma que existe GameStoreLogin.class en la misma carpeta.
