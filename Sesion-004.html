III. Marco Teórico Breve

📐 1. Diagramas de Clases UML

Herramienta de modelado visual que permite representar la estructura de un sistema orientado a objetos, mostrando las clases, sus atributos (con su visibilidad como + público o - privado), métodos y las relaciones entre ellas.

🏗️ 2. Constructores y la Referencia this

  • Constructor: Método especial que se ejecuta automáticamente al crear un objeto para inicializar sus atributos.
  • this: Palabra reservada que hace referencia al objeto actual de la clase, muy útil para diferenciar los atributos de los parámetros cuando tienen el mismo nombre.

this es como decir "MI" en vez de repetir tu propio nombre: dentro de un método o constructor, en lugar de indicar explícitamente de qué objeto hablas, this apunta automáticamente "a mí mismo" (el objeto sobre el que se está ejecutando ese código en ese momento).

🔑 3. Métodos Especializados

  • Accessors (getters): Permiten consultar u obtener el valor de un atributo privado.
  • Mutators (setters): Permiten modificar o asignar un nuevo valor a un atributo privado.
  • toString(): Método para representar el estado del objeto en formato de texto.

⚠️ Errores Comunes al Empezar

❌ Error típico: Nombrar el parámetro del constructor igual que el atributo, pero olvidar escribir this.

✅ Cómo evitarlo: Cuando el parámetro se llama igual que el atributo, debes usar this.atributo = atributo; si no, Java asume que hablas del parámetro en ambos lados y el atributo se queda con su valor por defecto.

❌ Error típico: Declarar los atributos como public en vez de private.

✅ Cómo evitarlo: Los atributos deben ser private; el acceso controlado se hace solo a través de métodos getters y setters — eso es el encapsulamiento.

❌ Error típico: Escribir un getter sin la palabra return.

✅ Cómo evitarlo: Todo getter necesita return seguido del atributo que quiere devolver, o el método no entrega ningún valor.

PASO 2

Desarrollo del Trabajo 2 (Codificación Orientada a Objetos)

Lleva el modelo anterior al código fuente en Java. Implementa la clase Estudiante.java aplicando encapsulamiento, constructores, la referencia this, y los métodos getters, setters y toString.

JAVA 
public class Estudiante {
    // Atributos privados (Encapsulamiento)
    private int id;
    private String nombre;
    private int puntos;

    // Constructor por defecto
    public Estudiante() {
    }

    // Constructor parametrizado utilizando la referencia 'this' (Trabajo 2)
    public Estudiante(int id, String nombre, int puntos) {
        this.id = id;
        this.nombre = nombre;
        this.puntos = puntos;
    }

    // Métodos Accessors (Getters) y Mutators (Setters) (Trabajo 2)
    public int getId() {
        return id;
    }

    public void setId(int id) {
        this.id = id;
    }

    public String getNombre() {
        return nombre;
    }

    public void setNombre(String nombre) {
        this.nombre = nombre;
    }

    public int getPuntos() {
        return puntos;
    }

    public void setPuntos(int puntos) {
        this.puntos = puntos;
    }

    // Método especializado toString para mostrar la información del objeto
    @Override
    public String toString() {
        return "Estudiante [ID=" + id + ", Nombre=" + nombre + ", Puntos=" + puntos + "]";
    }
}

🤔 Antes de seguir: si en el constructor de Estudiante escribieras puntos = puntos; en vez de this.puntos = puntos;, ¿qué valor tendría el atributo puntos del objeto recién creado?

0 (el valor por defecto de un int) — sin this., Java entiende que le estás asignando el parámetro a sí mismo, y el atributo de la clase nunca recibe el valor real que le pasaste al crear el objeto.

Clase de ejecución

Crea una clase de ejecución PrincipalEstudiante.java para probar la correcta creación de objetos utilizando el constructor:

JAVA 
public class PrincipalEstudiante {
    public static void main(String[] args) {
        // Creación de objeto usando el constructor parametrizado
        Estudiante alumno1 = new Estudiante(1, "Carlos Mendoza", 450);

        // Uso de métodos mutators para actualizar datos
        alumno1.setPuntos(500);

        // Mostrar datos usando el método toString y accessors
        System.out.println(alumno1.toString());
        System.out.println("Nombre consultado con Getter: " + alumno1.getNombre());
    }
}
