1. ¿Qué es este programa?

CatalogoTiendaAvanzado.java es la ventana del catálogo de recompensas de GameStore Escolar, entregable de los dos trabajos de la Sesión 2:

  • Trabajo 1 (Paneles y Layouts): estructura la ventana con BorderLayout (norte / centro / sur), un JPanel con GridLayout para los productos, y un JScrollPane que agrega barra de desplazamiento cuando ya no caben todos los ítems.
  • Trabajo 2 (Componentes de selección): agrega un panel de filtros en la parte superior con JComboBox (categorías), JCheckBox (notificaciones) y JRadioButton agrupados con ButtonGroup (tipo de entrega).

2. Requisitos

Solo necesitas el JDK instalado (versión 17 o superior), igual que en la Sesión 1. Gratuito en adoptium.net (Eclipse Temurin).

✅ Verificar instalación

En una terminal: javac -version. Si responde con un número de versión, ya está listo.

3. Ejecutarlo por terminal (rápido)

PASO 1

Ubícate en la carpeta del código:

$ cd Sesion-02/codigo
PASO 2

Compílalo:

$ javac CatalogoTiendaAvanzado.java
PASO 3

Ejecútalo:

$ java CatalogoTiendaAvanzado
→ Se abre la ventana "GameStore Escolar - Catálogo Avanzado"

4. Ejecutarlo con un IDE (recomendado para editar)

Abre la carpeta Sesion-02/codigo con cualquiera de estos IDEs gratuitos:

Apache NetBeans

Abre el archivo, clic derecho → Run File (o el botón ▶ verde).

IntelliJ IDEA Community

Abre la carpeta como proyecto, clic derecho sobre main → Run.

Eclipse IDE

Importa el archivo, luego Run As → Java Application.

VS Code

Instala Extension Pack for Java, abre el archivo y pulsa Run sobre main.

5. Cómo usarlo (guía de prueba)

Con la ventana abierta, verifica lo siguiente:

  • El panel superior muestra el filtro "Filtrar:" con un JComboBox de categorías, una casilla "Recibir alerta por correo" y dos radio buttons "Digital" / "Físico" (solo uno se puede marcar a la vez).
  • El panel central muestra 6 botones de recompensas en una cuadrícula de 3 filas × 2 columnas (GridLayout).
  • Achica la ventana verticalmente: debe aparecer una barra de desplazamiento gracias al JScrollPane.
  • El panel inferior muestra el botón "Canjear Ítem".

Nota: en esta sesión los controles todavía no tienen lógica de clic asociada (eso se agrega con ActionListener, como se vio en la Sesión 1) — el objetivo aquí es la estructura visual con contenedores y layouts.

6. Problemas comunes

⚠️ Solución a errores frecuentes

❌ javac: command not found

✅ El JDK no está instalado o no está en el PATH. Instálalo desde adoptium.net y reinicia la terminal.

❌ No se ve ninguna ventana al ejecutar java CatalogoTiendaAvanzado

✅ Estás en un entorno sin interfaz gráfica (por ejemplo, SSH sin X11). Ejecuta el programa en tu escritorio local, no en un servidor remoto sin pantalla.

❌ Los botones del catálogo se ven amontonados o cortados

✅ Revisa que el JPanel central use new GridLayout(3, 2, 10, 10) y que esté envuelto en un JScrollPane antes de agregarlo con BorderLayout.CENTER.
